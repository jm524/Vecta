# Vecta

A local-first, multi-agent CLI developer tool. TypeScript + Ink interface, Go systems engine, JSON stdio bridge.

> **Status:** v0.1.0 in progress — Congressional App Challenge build sprint.

## Install

Coming soon.

## Architecture

- `interface/` — TypeScript terminal UI (Ink + React)
- `engine/` — Go systems binary (hardware scan, queue, crypto, device)
- `roles/` — Role definitions and prompt interfaces
- `state/` — Central TypeScript state managers
- `docs/` — Architecture and reference docs

See `docs/architecture.md` for the full design.
