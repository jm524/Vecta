# Vecta - CLI Agent Manager
Personal Passion project to create a open-source CLI that manages cloud and local agent. The CLI allows agents to communicate for a task and also provides cross chat memory; Mainly using typescript + INK, GO, and MongoDB or SQLite . Helping users manage their agents, making everything easy with prompting (for users to use multiple agents throughout a prompting process that all serve their own specific role. Ex. manager, coder, code reviewer, documenter, security checker, and a few more ideas) customization (users would be able to choose which local agents do best in their roles, allow them to remove or all roles), and also Vecta will reccomend which local agents might be best for their machine), and in general to make vibe-coding easier for all users. Improve efficient and your all in one CLI.
